Questions fréquentes

Je ne reçois pas le code de connexion

Regardez dans les indésirables. Le code expire au bout d’une heure ; « Renvoyer le code » en envoie un nouveau.

Comment inviter mon conjoint ou un proche ?

Dans Trame : Profil › Foyers › Inviter. Partagez le lien ou le code ; la personne rejoint votre foyer après s’être connectée.

Voir Trame dans Google Agenda ou Outlook, et l’inverse

Profil › Google et Outlook. Un lien d’abonnement affiche l’agenda du foyer dans Google ou Outlook ; l’adresse secrète iCal d’un agenda Google ou Outlook l’affiche dans Trame.

Les notifications n’arrivent pas

Réglages de l’iPhone › Notifications › Trame : autorisez-les. Dans Trame, Profil › Notifications règle les rappels et les nouveautés du foyer.

Supprimer mon compte

Profil, tout en bas : « Supprimer mon compte ». La suppression est immédiate et définitive ; voir la politique de confidentialité.
